# 💳 Credit Card Analytics Dashboard

## 📌 Project Overview

This project presents an interactive **Credit Card Analytics Dashboard** developed using **Tableau** to analyze customer spending behavior, transaction trends, digital payment usage, and customer segmentation.

The dashboard helps businesses gain valuable insights into:

* 💰 Customer spending patterns
* 📈 Transaction growth trends
* 🌐 Digital channel usage
* 👥 Customer engagement
* 💳 Card category performance

---

# 🎯 Objectives

✔️ Analyze overall digital spending trends
✔️ Track monthly transaction performance
✔️ Identify active and dormant customers
✔️ Compare spending across platforms and card types
✔️ Perform customer segmentation analysis
✔️ Forecast future transaction trends
